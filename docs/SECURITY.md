# Границы доверия

Консоль только loopback: точные Host/Origin, JSON и размер тела, CSP/no-store, текст через textContent. В полном режиме предметные HTTP события веб-демо запрещены. Пользователь компьютера — доверенный оператор; публичная production-консоль не заявляется.

MAX вход требует одноразовой ссылки. Проверяется отправитель и личный чат. Приглашённый пользователь не переключает роль. Прежний тестовый оператор сохраняет разрешённое переключение. Native приглашения принимаются штатным способом, caller не задаёт роль. Отзыв прав проверяется ядром при действиях.

Кнопки/страницы привязаны к отправителю, чату, профилю и TTL. Квитанции защищают от повторов и конфликтов. STARTED до записи/отправки отличает законченный результат от неизвестного. Unknown не повторяется автоматически.

Каталоги runtime 0700, файлы 0600; symlink/чужая база отвергаются. Native пароли случайны и остаются приватными. Реальные MAX ID не импортируются как предметные пользователи. Токены, пароли, настройки, базы, ссылки и сырые логи исключены из Git/архивов.

Разрешён настоящий реактивный MAX через Long Polling: bot/subscriptions/updates, ответы, callback ack и файлы. Никаких webhook и инициативных рассылок. TLS включён; дополнительный CA действует только в клиенте. Credential не попадает в query/body, файл, CDN или сообщение. Импорт дополнительно выполняет native проверки формата и preview/apply.

Ядро не получает env сайта и облачные ключи. NanoGPT: явный отдельный ключ настраивается явно; облачного fallback нет. Текст ИИ не меняет права и не запускает команды. Назначения и публикации проходят штатные проверки и подтверждение человека.


Перед выдачей сохранённой страницы, файла и перед отправкой из outbox повторно проверяются текущие native права. Архив личной записи ученика закрывает и старый кэш. PDF и переданный материал дополнительно проверяют текущий документ/версию/grant; generic GET страницы сверяют свежий fingerprint. Полученный MAX batch сначала сохраняется в приватный spool; восстановление обрабатывает его до нового запроса к API, курсор и удаление batch фиксируются атомарно.
