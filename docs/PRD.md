# Требования к «Школе действия» в MAX

Школа работает с расписанием, заменами, учебными материалами и заданиями. На демонстрационном стенде используются вымышленные данные. Из публичного меню MAX можно выбрать одну из четырёх ролей и войти в веб-кабинет. Личный кабинет в чате открывается по приглашению и работает на отдельном ядре.

| Роль | Основные действия |
| --- | --- |
| Ученик | Просмотр заданий, отправка работы, чтение комментариев преподавателя |
| Преподаватель | Просмотр расписания, подготовка материалов, выдача и проверка заданий |
| Завуч | Ведение расписания и календаря, рассмотрение обращений, публикация замен |
| Директор | Просмотр отчётов, публикаций и списков школы |

Личные действия доступны в пределах закреплённой роли. Перед изменением система проверяет права, состояние записи и её версию. Повтор одного события не дублирует действие. Диалоги и квитанции сохраняются после перезапуска.

Веб-школа отправляет адресные уведомления о заменах и ответах на обращения в подтверждённый чат сотрудника. Попытка с неопределённым результатом отправки требует проверки перед повтором.

Преподаватель может готовить и проверять материалы вручную. На демонстрационном стенде генерация материалов отключена.
