# Код

Python 3.12, FastAPI, SQLite стандартной библиотеки. Небольшие модули: HTTP-граница, доменные команды, хранилище, synthetic MAX transport. Не добавлять скрытый сетевой или AI fallback. Реальный MAX доступен только отдельному явно включённому live-клиенту и worker. HTTP DTO строгие, SQL параметризованный, часы и UUID серверно/явно проверяются.

Статический JS без новой сборочной цепочки, семантический HTML и доступные формы. Пользовательский текст через textContent. Все пути runtime вычисляются относительно этого проекта, не прежней платформы. Для проекта создана собственная .venv. Полный одинаковый список версий записан в requirements.txt и requirements.lock. Исходная среда сайта для запуска не требуется.
