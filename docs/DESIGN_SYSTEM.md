# Дизайн

Материал Contour по действующему навыку Владислава: тонированное стекло с мягким бликом, сдержанная кромка, резкий текст, полные светлая и тёмная темы. Выбор темы видим и сохраняется безопасно. Учитываются системная тема, reduced motion/transparency и fallback без blur.

Композиция полной версии: спокойная шапка «Идеяфикс», пометка «Тестовые данные · личные кабинеты MAX», выбор профиля для личного приглашения и состояние настоящего Long Polling. На узком экране панели располагаются последовательно. Все предметные действия пользователь выполняет в настоящем MAX. Прежний веб-чат сохранён только для режима совместимости и скрыт в полной версии.

Состояния: loading, пустой чат/список, ошибка запроса с возможностью повторить ввод, disabled отправка во время запроса, видимый фокус. Пользовательский контент не вставляется через HTML.


В полном режиме страница — консоль подключения, старые веб-чат и карточки состояния скрыты. Пользовательский интерфейс — native MAX с личными кнопками, краткими вопросами и подтверждением изменений. Никакой имитации работы функций в скрытом веб-чате.
